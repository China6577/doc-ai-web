## 环境备忘（本机 PowerShell/Bash 坑）

- Bash 工具环境损坏（无 ls/dirname），用 PowerShell；且 PowerShell 工具 stdout 不显示，需写文件再 Read。
- npm 全局 .cmd shim 内含 exit，直接 `& x.cmd` 会杀掉宿主 PowerShell；agent-browser 是原生二进制包（无 playwright-core 可 require），需用 `node bin/agent-browser.js` 且 open 命令前台驻留（放后台任务当 daemon 用，其余命令另开 PowerShell 连接）。
- 项目 `"type": "module"` 下临时 node 脚本要用 `.cjs` 后缀。
- 安全策略会拦截含 "screenshot"/Remove-Item -Force 等命令且随会话升级，勿纠缠，换思路或留现场。
